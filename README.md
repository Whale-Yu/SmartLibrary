# SmartLibrary（SmartLib）介绍
SmartLib是一个智能图书馆预约签到系统，用于自动完成图书馆座位的预约和签到任务。系统支持自动预约、自动签到、邮件通知等功能，旨在为用户提供便捷的图书馆座位预约体验。
